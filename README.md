# タスクボード（担当者別ガントチャート）

学習用の演習課題（ドリル09：議事録から担当者別のアクションを抽出する課題）の発展として作成した、
ローカル完結型のタスク管理ツールです。

## 概要

- 担当者ごとにタスクを縦に並べ、期間を横のカレンダー（ガントチャート）で表示します。
- `taskboard.html` 1ファイルのみで完結し、外部通信・外部ライブラリ・CDN依存は一切ありません。
- データはブラウザの localStorage にのみ保存されます（サーバーやビルド工程は存在しません）。

## 使い方

`taskboard.html` をブラウザ（Chrome / Edge など）でダブルクリックして開くだけで動作します。
インストールや通信環境は不要です。

## 主な機能

- 担当者別グルーピングのガントチャート表示（横スクロールカレンダー、上下ともにフリーズ表示）
- バーのドラッグ移動・端のドラッグによる期間変更
- 期限に応じたステータス自動色分け（余裕あり／期限間近／期限超過／完了／不要）
- タスクへのリンク登録（フォルダ・ファイル・URL）
- タスク同士の「つながり」を線で可視化する接続機能
- CSV（Excel）出力・JSON書き出し／読み込みによるバックアップ・他PCへの移行
- Outlookでの更新通知メール下書き作成（任意でON/OFF可能）

## データについて

すべての入力内容はこの端末のブラウザ内にのみ保存され、外部には一切送信されません。
